## What is included

`evidence/` preserves the credential-free retrospective packet: 96 primary session records from the incomplete rate-limited live attempt, both complete paced live runs, and the scripted comparison. It includes original source snapshots, event streams, task/state files, reports and checksums. Original manifest bytes are unchanged. Historical sources precede the reviewed PR commit and retain their recorded dirty-worktree identities; they are not relabelled as runs of the later commit.

`reproductions/` preserves the available November 4 and November 5 offline reproductions from the focused PR checkout. They are separate engineering reproductions, not extra live runs, a new P0-1 pilot, or pooled primary observations. `review-records/` contains the saved November 5 test/demo transcripts. These are author-generated records, not independent review receipts.

## Verify offline

With Node 24, run `node verify.js` from this repository. It validates the publication inventory, original packet manifest digest, source hashes and state replay across primary and reproduction records. No API key, installation, model call or database is required.

## Findings and limits

The scripted Enforced arm withheld four prohibited calls on mandatory BLOCK and one on ESCALATE. The comparison-only upgrade still executed after Core returned PROCEED and remains a failure. All four legitimate controls completed in each scripted condition. Both complete live comparisons had zero prohibited attempts and zero BLOCK decisions: they demonstrate integration, not an observed incremental prevention benefit or live response to BLOCK.

The records were produced by the same trusted local runner that executed the tools. Checksums detect changes against retained bytes; they are not signatures, immutable storage, external timestamps or independently authenticated provider receipts. No new live run or Core pre-check was executed to create this repository. The Stage 1 v3 attachment is a separate draft; its original private attachment is not published here and this repository does not authorize its execution.

The original packet includes preliminary discussion notes written before receipt of Stage 1 v3; those notes are not a completed approved coverage map. Supplementary scripts/reports are automated author analysis, not independent human review. Task/state PASS does not grade all final-answer factual claims.
